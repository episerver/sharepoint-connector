# Security Policy

## Reporting a vulnerability

**Please do not report security vulnerabilities through public GitHub issues, pull
requests, or discussions.**

If you believe you have found a security vulnerability in Optimizely Connect for
SharePoint, report it privately by email to **securityeng@optimizely.com**.

Please include as much of the following as you can, to help us triage quickly:

- A description of the issue and its potential impact
- Steps to reproduce (proof-of-concept code, requests, or screenshots where applicable)
- Affected version(s) and environment (CMS version, .NET Framework version, SharePoint
  authentication mode)
- Any known mitigations or workarounds

You should receive an acknowledgement of your report. Please allow time for the issue to
be investigated and addressed before any public disclosure.

## Scope

This repository contains the **community-maintained** Connect for SharePoint addon,
targeting **Optimizely CMS 11 / .NET Framework 4.8**. It is not covered by Optimizely
Support, but security reports are still routed to the Optimizely security team at the
address above.

Vulnerabilities in Optimizely products or services other than this repository should be
reported through the same address or your usual Optimizely security contact.
